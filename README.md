# 铲子 AiSAST

**铲子 AiSAST** 是铲子科技推出的 AI 智能静态安全审计工具(SAST),可对 Java、Python、JavaScript、TypeScript、Go、C# 等多语言代码仓库进行自动化安全扫描与漏洞分析。支持自定义大模型接入,内置多阶段审计流程与四层漏洞验证防线,显著降低误报率。

## 下载安装

前往 [Releases](https://github.com/Chanzi-keji/aisast/releases) 页面下载最新版 Windows 安装包。

安装包内置 JRE 与全部运行时依赖,**无需预装任何环境**,下载后双击即可安装使用。
