**铲子 AiSAST** 是一款面向真实攻防场景的 AI 多智能体代码安全审计桌面工具。输入源码目录或 Git 仓库,它会自动完成「项目分析 → 全局审计 → 漏洞预筛 → API 提取 → 逐 API 审计」全流程:为每个接口收集完整调用链、按漏洞类别逐一审计、结合业务场景验证漏洞真伪,最终给出**调用链代码证据 + 可视化攻击链路 + 可复核的 HTML 报告**。

审计全程在你的电脑上运行,代码仅发送至你自己配置的大模型;安装包内置 JRE,开箱即用。

> 本仓库仅发布安装包与版本说明,不包含源代码。

## 核心优势

| 优势 | 说明 |
| --- | --- |
| **审得深** | 多个智能体按漏洞类别分工,对每个接口做「调用链收集 + 逐类别审计」,而不是把整个项目丢给模型一次性粗扫 |
| **误报低** | 适用性预筛先排除没有攻击前提的类别,漏洞有效性验证再结合业务场景逐条判定,双重把关 |
| **有证据** | 每条漏洞都能展开到调用链代码、生成攻击链路图,直接看到「入口 → 传递 → 危险点」的完整路径 |
| **省成本** | 不适用的类别零 token 跳过;攻击图按需生成、结果缓存;提示词布局针对大模型缓存优化,重复内容尽量复用 |
| **不怕中断** | 每个阶段的进展实时落盘快照,软件重启后完全还原进度;重扫自动复用已有成果 |
| **数据自主** | 审计全程在本机执行,前后端仅通过 127.0.0.1 回环通信,代码只发送至你自己配置的大模型 |

## 五阶段扫描流水线

| 阶段 | 做什么 | 为什么重要 |
| --- | --- | --- |
| **1. 项目整体分析** | 自动识别项目结构、技术栈、依赖清单、鉴权方案与敏感配置,压缩成全局背景上下文 | 后续所有阶段共享同一份项目认知,避免对每个接口重复解释项目 |
| **2. 全局漏洞审计** | 审计硬编码敏感信息、安全配置错误、CORS、JWT/Session 等全局性风险,每类只审一次 | 这类问题不属于单个接口,集中一次审完,不重复消耗 token |
| **3. 适用性预筛** | 特征匹配 + AI 判定双重把关,检查每类漏洞在当前项目中是否存在攻击前提 | 没有攻击前提的类别直接跳过,显著减少无效调用与误报 |
| **4. API 提取** | 静态扫描主流框架路由声明,AI 核对补全,并对每个符号做存在性校验 | 接口清单不完整,后面所有审计都会漏;符号校验防止 AI 编造不存在的接口 |
| **5. 逐 API 漏洞审计** | 并行收集每个接口上下游调用链,再按漏洞类别逐一审计,结论与代码证据同步落盘 | 这是审计的主体:每个接口、每个类别都有独立结论与证据 |

### API 提取的四层防线

AI 提取接口清单最怕「漏接口」和「编接口」,铲子 AiSAST 为此设计了四层防线:

1. **规则扫描层**:覆盖主流声明式路由(Spring、gin、Flask、Django、Express 等),并支持 ThinkPHP 等约定式自动路由与 PHP8 属性路由;对 controller / handler 目录下的公共方法做通用约定式识别
2. **AI 提取层**:对规则扫描的线索进行 AI 核对与补全,内置轮次预算纪律,到点强制输出,并预留追问轮兜底
3. **确定性降级层**:AI 提取异常时,直接把规则扫描线索转换为接口清单继续走后续流程,保证任务不中断
4. **分批提取层**:对完全陌生的自研框架,按顶层目录分批提取,降低单次上下文压力

四层全部失败才会标记任务失败——任务始终可见、可重试,不会静默丢失。

## 快速扫描模式

适合「大项目先摸底」的场景。开启后不需要从头审完全部接口:

- **高危 API 打标**:「AI + 静态规则」双引擎对全部接口打风险标签,优先锁定含鉴权缺失、危险函数调用、参数直入等特征的接口
- **专用并发通道**:打标出的高危接口使用独立并发配额优先审计,不被普通接口排队拖慢
- **动态池扩容**:扫描过程中根据任务规模动态调整并发池大小,项目再大也能快速出第一批判定结果

## 攻击链路图 — 漏洞攻击路径可视化

每个接口在审计完成后都有一条完整的攻击传播路径,但文字描述难以快速理解。铲子 AiSAST 把它画成图:

- **单接口攻击图**:在任意 API 上点击「攻击链路图」,AI 会读取该 API 的全部风险漏洞与调用链,整合成一张结构化攻击数据流图,前端自绘 SVG 渲染
- **颜色语义**:蓝色 = 攻击入口(接口参数),灰色 = 数据传递 / 校验节点,红色 = 危险点(危险函数调用、敏感操作)
- **任务级攻击链路总图**:扫描完成后可生成任务级总图,把所有已生成的单接口攻击图按漏洞类型聚合,自上而下展示每个漏洞从入口到危险点的完整传播链路,项目整体风险分布一图尽览
- **按需生成 + 缓存复用**:攻击图点开才生成,懒加载 + 本地缓存,同一个 API 重复查看不重复计费;缓存基于漏洞指纹,漏洞有更新才会重新生成
- **扫描中即可生成**:不必等任务结束,有风险的接口在扫描进度页即可直接生成攻击图
- **行号三层校准**:图节点引用的代码行号经过「审计发现预校准 → 标识符反查(±40 行窗口唯一定位)→ 旧缓存读时校准」三层处理,点击节点跳转源码行号准确
- **新标签页大视野**:攻击图与链路代码默认在新标签页打开,支持节点悬停放大等交互,图再大也看得清

## 链路代码 — 调用链逐跳查看

- 每个 API 的完整上下游调用链,按安全敏感度分级收集:安全敏感的危险点保留完整代码,普通分支只记录调用点与位置,兼顾信息完整与成本
- 结果页可逐跳展开每个调用节点,直接跳转源码对应行号
- 配合攻击链路图使用:图上看路径,代码里看细节

## AI 追问 — 审计结果上的随问随答

不是另开一个聊天窗口,而是直接在审计结果上追问:

- **三处入口**:攻击链路图页面、链路代码页面、每条漏洞详情,都可以直接发起追问
- **流式回答**:基于 SSE 流式推送,回答实时逐字渲染
- **会话持久化**:追问会话按「任务 + 接口 + 页面」维护,历史落盘,软件重启后仍可继续
- **按需深挖**:追问 Agent 默认直接根据审计素材作答,素材不足时才按需读取沙箱内代码、联网检索,不会无脑翻代码
- **独立记账**:追问消耗单独统计,与扫描成本分开,一目了然
- **失败友好**:模型调用失败或超时会返回明确错误提示,不会静默断流

## 组件漏洞审计

- 自动采集 pom.xml、build.gradle、package.json、requirements.txt 等依赖文件中的关键组件及版本
- 覆盖 fastjson、Log4j、Shiro、Struts2、Django、Flask、lodash 等跨语言高危组件的已知 CVE
- 组件漏洞作为全局类别,整个项目只审计一次,并纳入 HTML 报告

## 漏洞有效性验证

扫描给出的每个漏洞,都可以再经过一道「结合业务场景的验证」:

- **场景化判定**:读取漏洞上下文与业务逻辑,判断攻击是否真实可行,不只看代码特征
- **可视化结论**:误报打标红色「误报」,确认漏洞标记绿色「已确认」,结论同步体现在结果页与报告中
- **增量续验**:二次验证只处理未判定或已变更的条目,已判定项自动复用,支持与其他扫描任务并行
- **独立验证模型**:默认复用扫描模型,也可单独配置验证模型(厂商 / 密钥 / 模型 ID),验证结果记录实际使用的模型,便于追溯

## 统一审计口径

- **漏洞分类**:SQL 注入、XXE、越权、RCE、提示词注入、重放攻击、XSS、CORS、敏感信息泄露、条件竞争、业务逻辑等
- **定级一致**:高 / 中 / 低判定依据固化在审计与验证准则中,同一代码位置被多个接口引用时,定级必须一致,避免因上下文差异漂移
- **误报豁免**:内置豁免口径(例如管理端全字段回显不判泄露、无浏览器前端不构成 CORS 攻击面等),减少机械误报
- **证据原则**:结论必须基于可见代码证据,禁止推测式报告

## 断点续扫与动态排除

- **阶段快照**:每个阶段的进展即时落盘,软件崩溃或主动停止后重启,进度完整还原
- **成果复用**:重新扫描同一项目时,自动复用已完成的阶段与接口成果,只补未完成部分
- **动态排除**:扫描过程中发现某些接口无需审计(如已下线、非目标范围),可随时排除,即时生效且状态持久化;确认操作带二次确认,防误触

## 大模型支持与成本观测

- **11+ 厂商自动填充**:DeepSeek、通义千问、智谱 GLM、Kimi 等国内主流厂商,选择厂商即自动带出接口地址与推荐模型
- **自定义接口**:支持任意 OpenAI 兼容接口,可自定义 Base URL、模型 ID 与参数
- **测试连接**:保存前即可一键验证 API Key 是否可用
- **创建前预检**:新建任务时自动发起最小调用预检,未配置 Key、401/403 认证失败、402 余额不足、404 模型不存在、429 限流等问题直接拦截并说明原因,不会等扫完才发现白跑
- **用量观测**:按阶段、按会话查看 token 消耗与费用,明细可下钻
- **峰谷计费**:内置主流厂商高峰 / 低谷分时价格,费用估算更贴近真实账单

## 审计报告与过程分析

- **HTML 报告**:一键导出明暗双主题报告,逐 API 展开查看漏洞详情与调用链代码证据,可脱离软件独立打开
- **一键定位**:导出后可直接在系统文件管理器中定位报告文件
- **过程分析**:自动复盘扫描日志——每个阶段做了什么、耗时多少、哪些类别被跳过、失败重试情况,审计过程不再是黑盒

## 快速上手

1. 下载并安装对应平台的版本
2. 启动软件,在设置页选择大模型厂商并填入你自己的 API Key(可用「测试连接」验证)
3. 新建扫描任务:选择本地源码目录或填写 Git 仓库地址;大项目可先开启快速扫描模式摸底
4. 等待扫描完成,查看漏洞列表:点开攻击链路图看路径,展开链路代码看证据,对疑点直接 AI 追问
5. 需要时运行漏洞有效性验证,最后导出 HTML 报告归档
